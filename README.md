# Progetto-RFID-NFC
Progetto di ricerca sviluppato in team durante il corso di Cyber Security. L'elaborato contiene un analisi sulle tecnologie RFID ed NFC, in particolare sugli aspetti tecnici della sicurezza e delle soluzioni più comunemente adottate.
